# 같은 소스를 두 번 빌드했을 때 결과물이 같은가 (재빌드 승격이 왜 위험한지)

## Gradle 9.8.1 jar (기본 설정)
$ docker compose run --rm -T gradle-ci gradle -q --console=plain -p /work/lib clean jar -Pver=1.0.0 -Pcontent=same    # 3.2s, exit 0
  build 1: fb1d048304b251da
$ docker compose run --rm -T gradle-ci gradle -q --console=plain -p /work/lib clean jar -Pver=1.0.0 -Pcontent=same    # 2.8s, exit 0
  build 2: fb1d048304b251da
  같은가: True

## Gradle, preserveFileTimestamps=true 로 되돌리면
$ docker compose run --rm -T gradle-ci gradle -q --console=plain -p /work/lib clean jar -Pver=1.0.0 -Pcontent=same -PkeepTimestamps    # 2.7s, exit 0
  build 1: bf9b468885f567f3
$ docker compose run --rm -T gradle-ci gradle -q --console=plain -p /work/lib clean jar -Pver=1.0.0 -Pcontent=same -PkeepTimestamps    # 2.7s, exit 0
  build 2: 5201cbe1a29ae338
  같은가: False

## Maven 3.10.0 jar (기본 설정)
