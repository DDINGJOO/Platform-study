## 점검 근거

- 본문과 캡션이 해요체를 유지한다. 실제 관찰은 “확인했어요·남겼어요”, 일반 원리는 “사용해요·만들어요”, 후속 정리 명령은 “실습을 마친 뒤 … 실행하면 돼요”로 구분했다.
- 비유를 사용하거나 일반 동작을 비유적 서술어로 대체한 문장을 찾지 못했다. “생명주기”, “경로”, “복구”는 문맥상 기술 용어로 사용했다.
- 리터럴 엠대시와 `&mdash;` 모두 0개다. SVG 라벨도 점검했다.
- 절별 형광펜 개수는 1/0/1/0/1/1개다. 절당 1~2회 상한을 넘기지 않았고, 강조를 남발하지 않는다.
- Deployment·ReplicaSet·Service·EndpointSlice·NodePort 표기는 일관된다. 실제 API 필드 ready/serving/terminating과 Pod 조건 Ready는 코드 문맥으로 구분한다.
- 도입부의 네 질문은 모두 질문형이고, 코드 아래에 출력의 의미를 해요체로 설명한다. 설명 문장의 조사·어미가 생략된 명사구를 찾지 못했다.
- 마지막 요소는 요약 박스이며 다음 편 예고가 없다.
- 기존 51편과 대조했을 때 관찰 사실 → 출력 → 의미와 제한을 설명하는 문체가 일치한다.

원문 HTML과 다른 작업 파일은 변경하지 않았다. 검토 보고서만 작성했다.
