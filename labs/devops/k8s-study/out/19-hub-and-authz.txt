## 2. 인증(Authentication): 인증서 없이 API 서버에 요청
  curl -k https://192.168.104.1:6443/api/v1/namespaces/default/pods → 403 (anonymous 로 들어가 인가에서 막힘이면 403, 인증 실패면 401)
  응답 본문: 403 Forbidden | pods is forbidden: User "system:anonymous" cannot list resource "pods" in API group "" in the namespace "default"
  API 서버 플래그: --authorization-mode=Node,RBAC --client-ca-file=/etc/kubernetes/pki/ca.crt --enable-admission-plugins=NodeRestriction --service-account-key-file=/etc/kubernetes/pki/sa.pub

## 3. 인가(Authorization, RBAC): 인증은 됐지만 권한이 없는 사용자
  kubectl auth can-i list pods --as=system:serviceaccount:default:default → no
  kubectl get pods --as=system:serviceaccount:default:default → Error from server (Forbidden): pods is forbidden: User "system:serviceaccount:default:default" cannot list resource "pods" in API group "" in the name
  kubectl auth can-i list pods (관리자 kubeconfig) → yes
  관리자 kubeconfig 의 사용자: kubernetes-admin groups=["kubeadm:cluster-admins","system:authenticated"]

## 4. 어드미션(Admission): 저장 전에 API 서버가 요청을 고치고(mutating) 검사함 (--dry-run=server)
  내가 보낸 spec: containers 하나(name, image)만
  저장될 spec 에 붙은 것 (어드미션 플러그인이 붙인 것):
   [ServiceAccount]           serviceAccountName = default | volumes = ['kube-api-access-cqg7p']
   [DefaultTolerationSeconds] tolerations = [('not-ready', 'NoExecute', 300), ('unreachable', 'NoExecute', 300)]
   [Priority]                 priority = 0
  (그 밖에 API 기본값으로 채워진 것: imagePullPolicy = IfNotPresent , enableServiceLinks = True , preemptionPolicy = PreemptLowerPriority )
  API 서버 기본 어드미션 플러그인 목록 (kube-apiserver --help 의 --enable-admission-plugins 설명):
   NamespaceLifecycle LimitRanger ServiceAccount TaintNodesByCondition PodSecurity Priority DefaultTolerationSeconds DefaultStorageClass 
   StorageObjectInUseProtection PodGroupProtection PersistentVolumeClaimResize RuntimeClass CertificateApproval CertificateSigning 
   ClusterTrustBundleAttest CertificateSubjectRestriction DefaultIngressClass PodTopologyLabels NodeDeclaredFeatureValidator 
   PodResizeValidator MutatingAdmissionPolicy MutatingAdmissionWebhook ValidatingAdmissionPolicy ValidatingAdmissionWebhook ResourceQuota
