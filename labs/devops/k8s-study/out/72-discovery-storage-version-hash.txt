## 1. API 서버 버전과 emulation / min-compatibility 버전 (/version)

## 2. autoscaling 그룹: 두 버전을 서빙하고 그중 하나가 preferredVersion (/apis/autoscaling)
  versions: ['autoscaling/v2', 'autoscaling/v1']
  preferredVersion: autoscaling/v2

## 3. 같은 리소스를 다른 버전·다른 그룹 경로로 물어도 storageVersionHash는 같다
   (해시 = base64(sha256("<group>/<version>/<Kind>")[:8]), v1.37.2 storageversionhash.go)
  discovery 경로 / 리소스                                 storageVersionHash
  /apis/autoscaling/v1  horizontalpodautoscalers               qwQve8ut294=
  /apis/autoscaling/v2  horizontalpodautoscalers               qwQve8ut294=
  /api/v1  events                                              r2yiGXH7wu8=
  /apis/events.k8s.io/v1  events                               r2yiGXH7wu8=
  직접 계산:
    autoscaling/v1/HorizontalPodAutoscaler                     oQlkt7f5j/A=
    autoscaling/v2/HorizontalPodAutoscaler                     qwQve8ut294=
    /v1/Event                                                  r2yiGXH7wu8=
    events.k8s.io/v1/Event                                     x51sC10/5OA=
  → HPA는 v1으로 물어도 v2로 물어도 autoscaling/v2로 저장. events.k8s.io/v1 Event는 core v1 Event와 같은 저장소(/registry/events)를 쓴다.
