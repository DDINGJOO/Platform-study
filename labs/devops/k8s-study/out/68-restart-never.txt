# 읽는 법 (2026-11-15 추가)
# - never-native: 파드 restartPolicy는 Never인데 사이드카 crashy는 exit 1 뒤 다시 뜬다(재시작 2회, 그 뒤 CrashLoopBackOff).
#   app이 exit 0으로 끝나자 파드는 Succeeded. crashy의 마지막 exit 1은 phase에 안 들어간다(getPhase가 끝난 사이드카를 건너뜀).
# - crashy의 최종 exit 137은 실제 SIGKILL이 아니다. app이 끝날 때 crashy는 BackOff로 기다리던 중이었고,
#   kubelet status_manager.TerminatePod가 기다리던 init 컨테이너에 137/ContainerStatusUnknown을 채워 넣은 값이다
#   (sources/k8s-v1.37.2-kubelet-sidecar-excerpts.txt 끝 절).
# - never-old: 옛 방식 사이드카는 한 번 죽으면 그대로(재시작 0)이고, app이 성공해도 파드는 Failed. KEP-753 Motivation의 OOM 사례와 같은 모양.
