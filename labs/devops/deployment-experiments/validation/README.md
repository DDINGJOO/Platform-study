# 검증 기록

이 디렉터리는 실행 결과, 독립 검수, 발행 확인을 구분해 기록한다. 모든 실습은 합성 데이터와 로컬 컨테이너를 사용한다.

- `baseline.json`: 작업 시작 커밋과 보존한 기존 변경.
- `review-*.md`, `review.json`: 저자와 다른 네 관점 퇴고 및 수정 이력. 1편과 2편은 각각 본문 1건을 수정해 재검했고, 2편 검색 요약 누락은 통합 검사에서 별도로 보완했다.
- `audit.md`: 저자·퇴고자와 다른 감사자가 원자료와 실제 화면을 대조한 주장별 판정.
- `publication-mask-audit.md`: 숫자 등 일반 패턴 오탐에 대한 독립 분류. 조직 목록 적중에는 허용 목록을 적용하지 않는다.
- `checks.json`: 세 글의 HTML·SVG·템플릿·이미지와 데스크톱/모바일 표시 검사.
- `publication.json`: 이미지 커밋·원격 바이트 일치·업로드된 글과 공개 범위의 실제 확인.

루트 통합 검사에서 Python 16파일 구문 분석과 Compose 3개 설정을 확인했다. 실행 중인 1편의 Kayenta 입력·Prometheus·Gate 보고서 대조, 3편 HTTP 다섯 판정과 14개 테스트가 통과했다. 2편의 재시작·재시도 결과는 저장된 HTTP 이벤트와 독립 재계산으로 대조했다. 같은 실험을 덮는 runner 재실행은 최종 검수에 사용하지 않았다.

HTML 검사는 저장소의 추적된 스크립트와 템플릿을 사용한다. 브라우저 검사는 기존 Playwright·Chrome 환경이 필요하다. 새 클론에서 로컬 스킬 심볼릭 링크가 없어도 정적 검사가 가능하다.

Kayenta 점수는 가중 분류 결과이며 제품 실험의 신뢰도나 배포 안전성을 보장하지 않는다. 통계의 최소 표본 수는 설명용 정책이고 검정력 계산 결과가 아니다. 자세한 범위와 재현 명령은 각 실습 README에 있다.
