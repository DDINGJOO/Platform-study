## 확인한 독자 경로

1. 할당·노출·전환을 처음 등장하는 자리에서 구분하고, 노출은 테스트 클라이언트의 확인이며 브라우저 렌더링 검증은 아니라는 한계를 밝힌다.
2. 해시 입력·직렬화·버킷 기준, 사용자 식별자 변경 및 salt 변경 위험, 기존 실험 설정 변경 시 기동 거부를 설명한다. 코드의 경로와 일치한다.
3. 요청 ID가 다른 재시도도 사용자·실험·이벤트 종류로 중복 제거하며, 구매 건수와 전환한 사용자 수의 차이를 명시한다.
4. Docker Compose/Python 전제, 실행 및 종료 명령을 제공한다. SQLite 볼륨은 유지하고, 기본 Compose 실험 대신 저장된 실험을 다시 여는 환경 변수 명령을 README에 제공한다. 재실행·수동 이벤트가 증거와 화면을 바꿀 수 있다는 주의도 있다.
5. 저장된 결과는 A 46/160, B 37/160과 일치한다. 할당 전체 기준 분석과 노출 사용자 기준 집계의 차이 및 노출에 의한 편향 가능성을 설명한다. 합성 전환율로 제품 승자를 정하지 않는다.
6. Grafana PNG와 출력 PNG를 직접 확인했다. 주요 사용자 수·비율·검증 결과를 읽을 수 있고, 같은 핵심 수치가 본문 텍스트에도 있어 축소된 이미지에만 의존하지 않는다.

## 검증 증거와 경계

- 세 Python 파일은 AST 구문 검사 통과.
- 2편의 상대 링크·이미지 경로는 존재한다.
- 문서 명령을 실제 스크립트와 대조했다. 독립 퇴고 중 서비스 실행·재기동·데이터 변경·재캡처는 하지 않았다.
- 이 판정은 독자 이해와 재현 안내에 한정한다. 기술 사실 전수 감사와 다른 두 편의 검토를 대신하지 않는다.
