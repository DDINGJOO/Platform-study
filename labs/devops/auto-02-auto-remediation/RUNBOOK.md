# AppErrorRatioHigh

app 의 30초 실패율이 5% 를 15초 넘게 넘었다.

## 자동 조치

remediator 가 이 경고를 받으면 app 을 재시작한다(`POST /admin/restart`, Docker 가 다시 띄운다).

- `MODE=capped` 이면 30분 안에 3번까지만 재시작하고, 그 뒤에도 다시 울리면 조치를 멈추고 사람을 부른다
- 사람이 불렸다는 것은 **재시작으로는 고쳐지지 않는 장애**라는 뜻이다

## 사람이 할 일

1. remediator 기록(`out/events.jsonl`)에서 자동 재시작 횟수와 간격을 본다. 간격이 일정하면 가동 시간에 비례해 나빠지는 원인(누수)을 의심한다
2. app 로그와 `app_start_time_seconds` 로 재시작 시각과 실패가 다시 시작된 시각의 차이를 잰다
3. 원인 스위치를 끈다: 이 실습에서는 `rm state/leak`
4. 실패율이 0 으로 돌아오는지 본다. 자동 재시작 기록과 이 절차의 시각을 사후 분석에 남긴다
