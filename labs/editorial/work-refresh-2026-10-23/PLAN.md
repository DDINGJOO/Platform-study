# Work 글 전체 퇴고 계획

대상은 `posts/Work`의 기존 HTML 112편이다. IaC 42편을 먼저 다듬고 비용·운영·DB 이관·보안·배치 글까지 빠짐없이 검수한다. 사용자는 전체 수정, 누락 태그 추가, 글별 작성 에이전트, 검수 후 기존 티스토리 반영을 요청했다.

1. 변경 전 커밋과 전체 글·게시물 번호·보존 대상의 해시를 고정하고 회귀 검증을 먼저 실행한다.
2. 한 글마다 별도 작성자를 배정한다. 허용된 동시 실행 슬롯을 채우며 완료된 자리에 다음 글을 배정한다.
3. 비유·과장·인위적인 반전·반복되는 교훈을 구체적인 상황·확인·판단으로 바꾼다. 기술 근거와 실제 경험은 유지한다. 태그는 공통 태그와 합쳐 최대 열 개로 맞춘다.
4. 작성자가 제안한 구체적인 제목을 기존 파일 경로와 글 번호를 유지하며 표시 제목에 반영한다. 긴 시리즈 목차는 현재 편과 직전 두 편으로 정리한다.
5. 작성자와 별도인 네 관점의 퇴고 및 독립 원자료 감사를 진행한다. 발견 사항은 원 작성자가 수정하며 최대 세 라운드 안에서 재검한다.
6. 코드·로그·링크·이미지·CSS·SVG 구조 보존, 전체 HTML, 조직 마스킹, 모바일·데스크톱 표시를 검증한다. 미확인 사실은 새 주장으로 만들지 않는다.
7. 기존 글 번호와 실제 공개 범위를 유지해 업로드하고 태그·본문·제목을 확인한다. 관련 파일만 커밋·push한 뒤 CI를 확인한다.

사용자의 후속 요청에 따라 검수를 마친 시리즈부터 단계적으로 커밋·push하고 티스토리 반영을 진행한다. 첫 배치는 IaC 작업일지 31편이다. 배치별 독립 퇴고·감사와 검증을 마친 뒤 해당 경로만 업로드하며, 나머지 글의 작성은 이어간다. 최초 112편의 기준 커밋·공개 범위 스냅샷은 교체하지 않는다.

회사 원본 저장소는 읽기 전용이다. Notion이나 원본 서비스·인프라에는 쓰지 않는다. 기존에 있던 미추적 스킬·에이전트 파일은 보존한다.
