# Work 112편 퇴고·티스토리 반영 결과

IaC부터 비용·운영·DB·보안·배치까지 `posts/Work` 기존 112편의 문체를 다듬고 검색용 태그, 표시 제목, 도입 요약과 시리즈 목차를 정리했다. 글마다 작성자를 따로 배정하고 여덟 배치로 나눠 기존 티스토리 게시물에 반영했다.

## 검수와 보존

- 배치마다 작성자와 다른 네 관점의 검토와 별도 원자료 감사를 진행했다. 수정 후 재검했으며 각 배치의 최종 편집 지적은 0건이다. 보고서는 `reports/`, 배치별 결과는 `batch01-summary.json`부터 `batch08-summary.json`에 있다.
- 112편의 보호 영역 회귀 검사와 조직 마스킹을 통과했다. 기존 파일 경로·게시물 번호·공개 범위를 유지했다. CSS·이미지·실행 코드·로그와 외부 링크를 보존하고 SVG는 텍스트만 수정했다.
- 보호된 비용 예시 두 편의 절대 회사 금액은 검토된 예외로 비율·배수로 바꿨다. 정확한 예외와 해시는 `cost-redactions.json`에 있다. 최초 기준 `baseline.json`은 교체하지 않았다.
- 모바일·데스크톱 224개 화면에서 새 넘침과 SVG 잘림은 0건이다. 원래 있던 긴 코드의 넘침 8개 화면은 유지했다.

## 반영 확인

- 112개 실제 게시물의 제목·태그·정규화한 본문 텍스트 전체·SVG 개수·기존 공개 범위를 대조했다. 먼저 실게시 대조를 마친 96편은 현재 렌더 해시·글 번호·제목·태그·공개 범위가 검증 당시와 같음을 다시 확인해 증거를 승계했고, 마지막 16편은 업로드 후 새로 실게시를 읽었다. 모두 일치한다. 각 확인 시점은 최종 JSON에 구분했다.
- Work 밖의 기존 매니페스트 항목 142개는 유지했다. 마지막 업로더 계획의 남은 동작은 0건이다.
- 전체 실게시 증거: `publication-through-112.json`. 화면 검사: `browser-checks-through-112.json`. 보존 검사: `checks.json`. 최종 업로드 계획: `upload-plan-final.json`.

## 남은 근거 한계

과거 운영 로그·배포·테스트·보안 조치와 후속 완료를 직접 대조할 원본이 없는 주장은 본문에서 당시 기록 또는 확인 불가로 한정했다. 현재 코드나 실습 결과를 과거 운영 성공의 증거로 소급하지 않았다. 관찰 필터와 과거 집계표의 모집단 불일치는 보존 인용 바로 옆에서 명시했다.

법령 조문·판본의 독립 대조나 해당 서비스 적용을 재확인하지 못한 부분, 반복 실행별 원시 기록이 없는 부분도 본문과 감사 보고서에 한정했다. 편집 지적 0건은 모든 역사적 사실의 독립 입증을 뜻하지 않는다. 회사 자료 저장소와 Notion에는 쓰지 않았다.
