# 공개 전 원자료 마스킹 독립 감사

판정: **APPROVE**. 검토한 정확한 값에 대한 `.mask-allow` 등록을 승인한다. 실제 계정 ID·자격증명·개인정보 또는 미설명 후보는 발견하지 않았다. 검사기 변경이나 패턴 전체 허용은 이 승인 범위에 포함하지 않는다.

작성자·퇴고자와 분리된 최종 감사자가 원자료에서 각 후보의 필드와 로그 문맥을 직접 확인했다. 원자료를 수정하거나 실습을 재실행하지 않았다. 이 보고서는 앞선 32개 기술 주장 감사와 별도인 공개 전 검사 기록이다.

## 범위와 집계

대상은 `labs/observability/otel-practice/`와 `posts/CS/Observability/otel-practice/`의 실습 코드·설정·실행 증거·글·캡처다. 최초 요청의 대상은 155개 파일이었으며 감사 중 공통 증거 파일 추가로 156개가 되었다. 조직 고유 목록 검사 결과는 주 실행자가 별도 확인한 0건을 전달받았고, 이 감사의 독립 대조 대상은 일반 패턴 후보였다. 조직 고유 목록 자체나 내용은 이 보고서에 포함하지 않는다.

숫자 고유 후보 **957개 전부**에 대해 실제 발생 문맥을 대조했다. 아래 분류는 상호 배타적이며 합계가 957개다.

| 분류 | 고유 값 수 | 근거 문맥 |
|---|---:|---|
| 로컬 실행 타임스탬프 | 604 | 스팬·로그 UnixNano, Loki 레코드 시각, SQLite 수신 시각 |
| 측정 지연·처리량·메트릭 소수부 | 335 | Tempo 요청 지연·처리량 및 Collector 메트릭 |
| 합성 span ID | 1 | Collector 유실 실습이 임의 생성한 span ID |
| 소프트웨어 시간 상수 | 2 | Collector health check 시간 설정의 ns 표기 |
| Docker 이미지 크기 | 4 | `docker compose images` 결과의 bytes |
| Grafana 출력 크기 상수 | 1 | 기본 Alertmanager의 `maxTemplateOutput` |
| 로컬 Alertmanager 설정 해시 구성값 | 7 | Grafana 기본 설정의 `configHash` |
| 로컬 Grafana resourceVersion | 2 | `sql-resource-server`의 `rv`·`nextRV`·`listRV` |
| Loki 조회 기간 | 1 | 조회 통계 `statsResult.queryLengthServed`의 ns 표기 |
| **합계** | **957** | **미설명 0** |

AWS 계정 ID로도 탐지된 12자리 값 3개는 모두 Tempo `request_throughput`의 소수부다. 위 335개에 이미 포함되므로 별도 숫자 후보로 더하지 않는다.

추가 일반 패턴 후보는 공개 Go 모듈명과 버전 표기 7개, 로컬 Docker 네트워크 주소 2개다. 모듈 후보는 Collector 스택 로그의 소스 경로이고 이메일이 아니다. IP 후보는 로컬 실습 HTTP 클라이언트 주소와 Collector에서 Tempo로 보내는 gRPC 대상이다.

따라서 정확한 값 기준 허용 후보는 **966개(숫자 957 + 모듈 7 + IP 2)**다. 각 값에 대한 분류와 사유는 작업용 임시 JSON으로 주 실행자에게 전달했으며, 후보 원문은 이 보고서에 싣지 않는다.

## 승인 범위

- 이번에 대조한 정확한 값과 해당 실습 문맥에 한정한다.
- 일반 숫자·이메일·사설 IP 패턴 전체를 허용하는 승인이 아니다.
- 조직 고유 목록 적중이나 이후 새로 추가되는 후보를 면제하지 않는다.
- 주 실행자는 실제 `.mask-allow` 반영 후 기존 검사기로 최종 스테이징 내용과 경로를 다시 검사한다.

미해결 항목: 없음.
