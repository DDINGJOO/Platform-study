# OpenTelemetry 심화 시리즈 검수 기록

기준일: 2026-10-21. 아래 검수는 로컬 초안 8편과 공개 소스 코드 이미지 18개를 대상으로 했으며, 그 단계에서는 발행·커밋·푸시를 하지 않았다. 이후 사용자가 요청한 커밋·푸시·업로드 결과는 [발행 기록](publication.md)으로 구분한다.

## 최종 편집

- 전체 목차와 별도의 전체 목록을 두지 않는다. 상단에는 현재 편을 포함한 최근 세 편만 남겼다. 4편은 2·3·4편, 8편은 6·7·8편이다. 첫 두 편은 존재하는 편만 표시한다.
- 도입부와 각 캡처에서 반복하던 긴 커밋·제작 방식·문서 확인일 고지를 제거했다. 원문 링크와 글 하단의 짧은 소스 기준은 유지했다. 정확한 버전·해시·발췌 범위는 편별 manifest에 남겼다.
- 원고는 문제·코드 분석·책임 경계·비교 기술·비용·미확인 범위를 구분한다. 실행하지 않은 예제를 실행 결과로 서술하지 않는다.

## 독립 퇴고

작성자와 분리한 네 관점에서 8편 전체를 읽었다. 1차 지적 4건을 모두 반영했고, 해당 검토자가 수정 후 해결 여부를 재확인했다. 미해결 0건이다.

| 관점 | 최초 지적 | 반영·재검 | 근거 |
| --- | ---: | --- | --- |
| 사실관계 | 0 | 공개 고정 소스·공식 문서와 핵심 주장 대조 | [보고서](../otel-review-facts.md) |
| 논리 | 0 | 인과·비교 계층·실행 범위 확인 | [보고서](../otel-review-logic.md) |
| 독자 | LOW 2 | temporality·cumulative/delta와 p95의 첫 등장 설명 보완, 모두 해결 | [보고서](../otel-review-reader.md) |
| 문장 | LOW 2 | 비유 두 곳을 실제 처리명·조건 설명으로 교체, 모두 해결 | [보고서](../otel-review-style.md) |

원자료 최종 감사는 작성자·네 관점 퇴고자와 다른 담당자가 완료했다. 중요한 주장 묶음 83건을 대조해 확인 83건, 불일치·확인 불가·과장 각 0건이다. 이는 모든 문장이나 모든 런타임 조합의 완전 검증을 뜻하지 않는다. 판정 항목과 직접 확인한 근거, 미확인 범위는 [별도 감사 기록](../otel-independent-audit.md)을 따른다. 자동 검사를 사실 감사로 간주하지 않는다.

## 자동 검사와 실행 증거

- [최종 검사](report.md): 8/8편 PASS, 정적·데스크톱·모바일 오류 0건. 1100×850 및 390×844 로컬 브라우저 검사와 32개 미리보기 이미지를 남겼다. 전체 페이지를 촬영한 검사는 아니다.
- 공개 raw 원문과 캡처 manifest의 파일 해시 18개를 대조했다. 대표 이미지는 별도로 육안 확인했다.
- 기존 추적 HTML 193편의 제목·카테고리·태그 설정 영향은 변경 0건이며 기존 업로드 manifest도 그대로다.
- [실행 실험](../otel-runtime-probes/README.md): API/SDK 구성, Context 복원, 배치 큐 포화, 샘플링의 네 probe를 각 5회 실행해 저장된 출력과 일치했다. 독립 감사자도 재실행했다. 공개 아티팩트 5개의 해시와 `javac --release 11 -Xlint:all`을 확인했다.
- [API-only 실험](../otel-01-api-sdk/README.md): SDK 없는 no-op과 부모 문맥 보존을 별도로 확인했다.

## 검증과 발행의 경계

초안 검수 단계에서는 실제 티스토리 스킨, 카테고리 존재 여부, 이미지 호스팅·링크 치환을 확인하거나 실행하지 않았다. 후속 발행 단계에서 카테고리와 CDN을 확인하고 PNG 참조·실험 자료 링크를 게시용 주소로 바꿨다. 초안 검수와 게시 페이지 검증의 범위는 구분한다.

메트릭·Collector YAML·Java agent·OBI·Micrometer bridge를 통합 실행한 결과가 아니다. upstream 전체 빌드·성능 측정·실제 OTLP 전송·백엔드 영속화도 검증하지 않았다. 초안 단계의 마스킹 검사는 공개 자료와 일반 규칙을 대상으로 했고, 후속 발행 단계에서는 저장소 밖의 조직별 금칙어 목록을 추가해 검사했다.
