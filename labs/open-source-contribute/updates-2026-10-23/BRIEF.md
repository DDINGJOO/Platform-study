기존 파일명·제목·시리즈 박스·CSS·SVG를 그대로 유지한다. 새 시리즈 박스를 만들지 않으며 이 작업은 기존 글의 사실 정정과 후속 상황 반영이다. 문체 기준은 각 글의 기존 본문이다. 요약·날짜·현재 상태·필요한 설명만 최소 수정한다. 과거 재현 SHA와 테스트 수치는 당시 기록으로 유지하고 새 head의 실행 결과로 바꾸지 않는다. 최신 코드를 직접 실행했다고 주장하지 않는다.

SCC의 새 공개 체크는 DCO 하나만 확인됐다. Bitbucket 링크가 없는 샘플을 전체 페이로드로 일반화한 부분은 바로잡고, 링크가 없으면 알림만 보내는 한계와 OPEN 상태를 유지한다. Spinnaker의 main 병합은 PR 고유 동작의 새 수정이 아니며, Mergify의 앱 권한 실패와 테스트 성공을 구분한다. Debezium의 새 CI 설명은 작성자의 주장이지 승인이나 근본 원인 입증이 아니다.

작성자는 자신의 두 HTML만 편집한다. 공통 ROADMAP·증거·허용 목록·manifest는 리더가 담당한다. 네 관점의 독립 퇴고자는 수정 diff를 원문과 대조하고 보고서만 쓴다. 작성자·퇴고자와 다른 감사자가 최신 원문을 대조한다. HTML·마스킹·브라우저 표시를 검증한 뒤 기존 글 번호로 업로드하고 현재 공개 범위를 유지한다.
